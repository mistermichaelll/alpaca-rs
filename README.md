
# alpaca-rs

A Rust wrapper for [Alpaca](https://alpaca.markets)'s API.

This started as a Saturday project for building something "real" in Rust. I'm still learning and want to emphasize that *this is a hobby project*. :)

Longer term, my goal for this project is to integrate it into some kind of automated backtester. Basically give a strategy a trial-by-fire in the Alpaca Paper Trading sandbox.
